# TALOS Evacuation Platform — UI Design System

## 1. Design Goals

The user interface must be:

- Professional
- Clear
- Fast to understand
- Consistent
- Responsive
- Suitable for emergency-management workflows

The interface must avoid unnecessary visual complexity.

## 2. Color Palette

### Primary Colors

- Primary Dark: `#0F172A`
- Primary Blue: `#2563EB`
- Primary Blue Hover: `#1D4ED8`

### Status Colors

- Success: `#16A34A`
- Warning: `#F59E0B`
- Danger: `#DC2626`
- Information: `#0284C7`

### Neutral Colors

- Page Background: `#F8FAFC`
- Card Background: `#FFFFFF`
- Border: `#E2E8F0`
- Primary Text: `#0F172A`
- Secondary Text: `#64748B`

The danger color must mainly be used for:

- Fire hazards
- Emergency alerts
- Destructive actions
- Failed system states
